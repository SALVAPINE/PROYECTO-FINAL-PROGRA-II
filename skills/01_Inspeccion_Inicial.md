# Skill 01 — Inspección inicial

Estado del instructivo: COMPLETO. Documento activo: 01.

## Objetivo
Identificar el proyecto real y acordar su estructura antes de programar o conectar SQL Server.

## Procedimiento
1. Usar CMD explícitamente en Windows; no usar PowerShell si CMD está disponible.
2. Consultar ruta y contenido con `cd` y `dir /a`; usar `tree /f /a` en las carpetas necesarias.
3. Leer README, reglas existentes, solución y proyectos. Verificar tecnologías y capas en archivos reales; no inferir funcionamiento por nombres o binarios.
4. Identificar formularios y diseños existentes para conservarlos. No generar CRUD, soluciones ni formularios.
5. Mostrar el árbol real al estudiante y solicitar confirmación antes de SQL Server.
6. Proponer la estructura documental; crearla solo tras autorización. Mantener skills, docs y database sin subcarpetas; src vacío en esta etapa.
7. Verificar los 11 nombres de skills y los archivos requeridos. Registrar hechos en MEMORY y estados en ESTADO_DOCUMENTOS.
8. Mostrar el resultado y preguntar antes del siguiente paso. Mantener documentos 02–10 bloqueados hasta autorización expresa.

## Evidencia disponible
El estudiante confirmó el árbol original y autorizó la preparación documental el 17/10/2026. Existen cuatro proyectos y diseños Windows Forms. Entidad declara .NET Framework v4.8. La conexión y los CRUD no fueron probados en esta etapa.

## Criterio de cierre
Estructura plana revisada, diseños conservados y estudiante conforme con el resultado. La confirmación del árbol no sustituye la autorización de la etapa SQL Server.
